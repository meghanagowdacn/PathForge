# 🚀 PathForge

> A full-stack career development and placement preparation platform for students.

PathForge helps students organize their career preparation in one place — from learning roadmaps and skill tracking to projects, interview preparation, resume building, and job application tracking.

## ✨ Features

- 🔐 Firebase Authentication
- 📊 Personalized Dashboard
- 🗺️ Career Roadmaps
- 🛠️ Skill Tracking
- 📁 Project Management
- ✅ Task & Study Planner
- 🎤 Interview Preparation
- 📜 Interview History & Scoring
- 📄 Resume Builder
- 🤖 AI Resume Analyzer
- 💼 Job Application Tracker
- 👤 Profile Management
- ⚙️ Settings & Theme Support
- 📈 Progress Tracking

## 🛠️ Tech Stack

### Frontend
- React
- Vite
- JavaScript
- CSS
- React Router

### Backend
- Node.js
- Express.js
- REST APIs

### Database & Authentication
- Firebase Authentication
- Firebase Firestore
- Firebase Admin SDK
